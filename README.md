# 냥토닥 – 취업 준비생을 위한 멘탈 케어 웹 서비스

작은 미션, 감정 일기, 캐릭터 커스터마이징을 통해  
쉼 청년과 취업 준비생이 다시 사회로 나갈 수 있도록 돕는 웹 애플리케이션입니다.

## 소개

냥토닥은 아래와 같은 순환 구조를 중심으로 사용자의 심리적 회복과 자기 동기 부여를 돕습니다.

미션 수행 → 포인트 획득 → 캐릭터 꾸미기 → 감정 일기 작성 → 캐릭터와 채팅

심리 상담이나 멘탈 케어에 대한 진입장벽을 낮추고,  
작은 행동과 기록을 통해 일상 회복의 루틴을 쌓는 것을 목표로 합니다.

## 주요 기능

| 기능                | 설명                                               |
| ------------------- | -------------------------------------------------- |
| 미션 수행           | 오늘 할 일을 미션으로 추가하고 완료 시 포인트 지급 |
| 캐릭터 커스터마이징 | 포인트로 아이템을 구매하여 고양이 캐릭터에 장착    |
| 감정 기반 일기      | 하루의 감정 상태를 함께 기록                       |
| 캐릭터와 채팅       | 캐릭터와 대화를 통해 심리적 위로 및 동기 부여      |

## 서비스 작동 흐름

```
미션 완료
  ↓
포인트 획득
  ↓
아이템 구매
  ↓
캐릭터 꾸미기
  ↓
캐릭터와 채팅
  ↓
감정 일기 작성
```

## 기술 스택

- Frontend: React, Vite, TanStack Query
- Auth: Google OAuth (토큰은 sessionStorage 저장)
- Backend: 별도 서버 배포 API 연동
